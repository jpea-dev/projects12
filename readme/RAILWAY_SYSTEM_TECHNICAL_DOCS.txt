## 3. FUNCTIONAL MODULES

### Module 1: Initialization Module

**Functions:**
- `initialize_files()` - Creates/initializes all data files
- `get_next_ticket_number()` - Generates sequential ticket numbers
- `get_next_passenger_id()` - Generates sequential passenger IDs

**Purpose:** Ensures all required files exist and are properly formatted

**File Operations:**
- Create trains.csv with 5 sample trains
- Create passengers.csv with header only
- Create bookings.csv with header only
- Create ticket_counter.txt with starting value 5000

### Module 2: Passenger Management

**Functions:**
- `add_passenger()` - Register new passenger
- `view_passenger()` - Display passenger details
- `passenger_menu()` - Submenu interface

**Workflow:**
```
add_passenger():
  1. Generate next ID
  2. Input: Name, Age, Gender, Phone, Email
  3. Validation:
     - Name length >= 2
     - Age: 1-120
     - Gender: M/F/Other
     - Phone: digits only, length >= 10
     - Email: contains @ and .
  4. Write to passengers.csv
  5. Display confirmation
```

**Data Validation:**
```python
Name:    len(name) >= 2
Age:     1 <= age <= 120
Gender:  gender in ['M', 'F', 'OTHER']
Phone:   phone.isdigit() and len(phone) >= 10
Email:   '@' in email and '.' in email
```

### Module 3: Train Management

**Functions:**
- `view_trains()` - Display all trains in table format
- `get_train_details()` - Retrieve specific train information
- `train_menu()` - Submenu interface

**Pre-loaded Trains:**
```
TR001: Rajdhani Express (Delhi → Mumbai) - 100 seats - Rs.1500
TR002: Shatabdi Express (Delhi → Jaipur) - 80 seats - Rs.800
TR003: Duronto Train (Mumbai → Bangalore) - 120 seats - Rs.2000
TR004: Express Train (Bangalore → Chennai) - 95 seats - Rs.600
TR005: Local Train (Delhi → Agra) - 150 seats - Rs.500
```

**Features:**
- Real-time seat availability display
- Detailed train information retrieval
- Formatted table output

### Module 4: Ticket Reservation

**Function:**
- `book_ticket()` - Create new ticket booking

**Workflow:**
```
book_ticket():
  1. Input: Passenger ID
  2. Verify passenger exists in passengers.csv
  3. Display available trains
  4. Input: Train Number
  5. Verify train exists and has available seats
  6. Generate ticket number (TKT5001, TKT5002, ...)
  7. Get current date
  8. Add booking to bookings.csv:
     - Ticket Number
     - Passenger ID
     - Train Number
     - Booking Date
     - Status: Confirmed
  9. Update trains.csv:
     - Reduce available seats by 1
 10. Display booking confirmation
```

**Validation Checks:**
- Passenger exists in database
- Train exists in database
- Available seats > 0
- Valid input format

**Data Updates:**
- bookings.csv: Add new row
- trains.csv: Decrement available seats
- ticket_counter.txt: Increment counter

### Module 5: Ticket Cancellation

**Function:**
- `cancel_ticket()` - Cancel existing booking

**Workflow:**
```
cancel_ticket():
  1. Input: Ticket Number
  2. Search bookings.csv
  3. Find ticket with status = "Confirmed"
  4. If found:
     a. Change status to "Cancelled"
     b. Get Train Number from booking
     c. Update trains.csv:
        - Increase available seats by 1
     d. Update bookings.csv with new status
     e. Display cancellation confirmation
  5. If not found:
     - Display error message
```

**Validation Checks:**
- Ticket exists in bookings.csv
- Booking status is "Confirmed"
- Cannot cancel already cancelled ticket

**Data Updates:**
- bookings.csv: Update status field
- trains.csv: Increment available seats

### Module 6: Reports Module

## 4. DATA STORAGE STRUCTURE

### File 1: passengers.csv
```
Format: Comma Separated Values
Header: PassengerId,Name,Age,Gender,Phone,Email
Row Example: P001,Raj Kumar Singh,25,M,9876543210,raj.kumar@email.com

Fields:
- PassengerId: String (P001, P002, ...)
- Name: String (2+ characters)
- Age: Integer (1-120)
- Gender: String (M/F/Other)
- Phone: String (10+ digits)
- Email: String (contains @ and .)

Size: Grows with each passenger registration
```

### File 2: trains.csv
```
Format: Comma Separated Values
Header: TrainNumber,TrainName,Source,Destination,AvailableSeats,Fare
Row Example: TR001,Rajdhani Express,Delhi,Mumbai,100,1500

Fields:
- TrainNumber: String (TR001-TR005)
- TrainName: String
- Source: String
- Destination: String
- AvailableSeats: Integer (0-Initial)
- Fare: Integer (ticket price in Rs)

Size: Fixed (5 trains, can be extended)
Note: AvailableSeats field updates with each booking/cancellation
```

### File 3: bookings.csv
```
Format: Comma Separated Values
Header: TicketNumber,PassengerId,TrainNumber,BookingDate,BookingStatus
Row Example: TKT5001,P001,TR001,21-01-2026,Confirmed

Fields:
- TicketNumber: String (TKT5001, TKT5002, ...)
- PassengerId: String (P001, P002, ...)
- TrainNumber: String (TR001-TR005)
- BookingDate: String (DD-MM-YYYY format)
- BookingStatus: String (Confirmed/Cancelled)

Size: Grows with each booking
```

### File 4: ticket_counter.txt
```
Format: Plain Text (Single Integer)
Content: Current ticket counter value

Example: 5001

Purpose: Maintains sequential ticket number generation
Updated: After each ticket booking
Initial: 5000
```

## 6. FILE I/O OPERATIONS

### Reading CSV Files
```python
with open(filename, 'r') as f:
    reader = csv.reader(f)
    header = next(reader)
    for row in reader:
        # Process row
```

### Writing CSV Files
```python
with open(filename, 'w', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(header)
    writer.writerows(data_rows)
```

### Appending CSV Files
```python
with open(filename, 'a', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(new_row)
```

## 7. ERROR HANDLING STRATEGY

### Error Categories
1. **Input Validation Errors**
   - Invalid format (type mismatch)
   - Out of range values
   - Missing data

2. **Data Lookup Errors**
   - Passenger not found
   - Train not found
   - Ticket not found

3. **Business Logic Errors**
   - No seats available
   - Cannot cancel confirmed booking
   - Duplicate operations

4. **File I/O Errors**
   - File not found
   - Read/write failures
   - Corruption detection

### Error Handling Pattern
```python
try:
    # Perform operation
    if validation_failed:
        print(f"\nError: {error_message}")
        return
    if file_operation_failed:
        print(f"Error: {error_message}")
except Exception as e:
    print(f"\nError: {str(e)}")
```
