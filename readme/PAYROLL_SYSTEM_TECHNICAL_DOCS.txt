## 2. Data Storage Schema

### 2.1 employees.csv Structure

**Location:** Same directory as Python file
**Format:** CSV (Comma-Separated Values)
**Encoding:** UTF-8

**Schema:**
```
Column 1: ID (String, Primary Key)
          Format: 4 digits starting from 1001
          Example: 1001, 1002, 1003, ...

Column 2: Name (String)
          Length: 1-100 characters
          Example: John Doe

Column 3: Designation (String)
          Examples: Developer, Manager, Executive, Clerk
          Length: 1-50 characters

Column 4: Department (String)
          Examples: IT, HR, Sales, Finance, Operations
          Length: 1-50 characters
```

**Sample Data:**
```csv
ID,Name,Designation,Department
1001,Rajesh Kumar,Senior Developer,IT
1002,Priya Sharma,HR Manager,Human Resources
1003,Amit Singh,Sales Executive,Sales
```

### 2.2 salaries.csv Structure

**Location:** Same directory as Python file
**Format:** CSV (Comma-Separated Values)
**Encoding:** UTF-8

**Schema:**
```
Column 1: ID (String, Foreign Key)
          Links to employees.csv ID
          Example: 1001

Column 2: BasicSalary (Float)
          Format: XXXXX.XX
          Example: 50000.00
          Range: 0 to 9999999.99

Column 3: HRA (Float)
          Calculated: BasicSalary * 0.10
          Example: 5000.00

Column 4: DA (Float)
          Calculated: BasicSalary * 0.05
          Example: 2500.00

Column 5: PF (Float)
          Calculated: BasicSalary * 0.12
          Example: 6000.00

Column 6: GrossSalary (Float)
          Calculated: BasicSalary + HRA + DA - PF
          Example: 51500.00

Column 7: NetSalary (Float)
          Currently equals GrossSalary
          Example: 51500.00
```

**Sample Data:**
```csv
ID,BasicSalary,HRA,DA,PF,GrossSalary,NetSalary
1001,50000.0,5000.0,2500.0,6000.0,51500.0,51500.0
1002,35000.0,3500.0,1750.0,4200.0,36050.0,36050.0
```

## 3. Function Reference

### 3.1 File Operation Functions

#### `initialize_files()`
```python
Purpose: Create CSV files if they don't exist
Input: None
Output: None
Side Effects: Creates employees.csv and salaries.csv if missing
Error Handling: Handles file creation errors gracefully
```

#### `load_employees()`
```python
Purpose: Read all employees from employees.csv
Input: None
Output: List[Dict] - List of employee dictionaries
Returns: Empty list if file doesn't exist
Fields: {'ID': str, 'Name': str, 'Designation': str, 'Department': str}
```

#### `save_employees(employees)`
```python
Purpose: Write employees to employees.csv
Input: employees (List[Dict]) - Employee data to save
Output: None (returns boolean indicating success)
Returns: True on success, False on error
Side Effects: Overwrites employees.csv completely
```

#### `load_salaries()`
```python
Purpose: Read all salary records from salaries.csv
Input: None
Output: List[Dict] - List of salary dictionaries
Returns: Empty list if file doesn't exist
Fields: {'ID': str, 'BasicSalary': str, 'HRA': str, 'DA': str, 'PF': str, 'GrossSalary': str, 'NetSalary': str}
Note: All numeric values stored as strings in CSV
```

#### `save_salaries(salaries)`
```python
Purpose: Write salary records to salaries.csv
Input: salaries (List[Dict]) - Salary data to save
Output: None (returns boolean indicating success)
Returns: True on success, False on error
Side Effects: Overwrites salaries.csv completely
```

#### `get_next_employee_id()`
```python
Purpose: Generate next available employee ID
Input: None
Output: String (e.g., "1004")
Logic: Find max ID from employees, add 1
Default: Returns "1001" if no employees exist
```

### 3.2 Employee Management Functions

#### `add_employee()`
```python
Purpose: Add new employee to system
Input: Interactive user input
Output: Console messages
Process:
  1. Generate next employee ID
  2. Get: Name, Designation, Department
  3. Validate: None are empty
  4. Create employee dictionary
  5. Append to employees list
  6. Save to CSV
  7. Display success message

Error Cases:
  - Empty name field
  - Empty designation field
  - Empty department field
  - File save error
```

#### `view_employee()`
```python
Purpose: Display employee details by ID
Input: Interactive - Employee ID
Output: Formatted employee information or error
Process:
  1. Get employee ID from user
  2. Load all employees
  3. Search for matching ID
  4. Display if found, error if not

Display Format:
  ID: [value]
  Name: [value]
  Designation: [value]
  Department: [value]

Error Cases:
  - Empty ID field
  - Employee not found
  - File access error
```

#### `update_employee()`
```python
Purpose: Modify employee information
Input: Interactive - Employee ID and new values
Output: Console messages
Process:
  1. Get employee ID
  2. Load all employees
  3. Find matching employee
  4. Display current information
  5. Get new values (optional)
  6. Update if new value provided
  7. Save to CSV
  8. Display success message

Update Fields:
  - Name (optional)
  - Designation (optional)
  - Department (optional)

Error Cases:
  - Empty ID field
  - Employee not found
  - File save error
```

#### `delete_employee()`
```python
Purpose: Remove employee and salary records
Input: Interactive - Employee ID and confirmation
Output: Console messages
Process:
  1. Get employee ID
  2. Request confirmation (yes/no)
  3. If confirmed:
     a. Load employees and salaries
     b. Remove matching ID from both lists
     c. Save both files
     d. Show success message
  4. If cancelled, show cancellation message

Error Cases:
  - Empty ID field
  - User cancels operation
  - Employee not found
  - File save error
```

### 3.3 Payroll Functions

#### `enter_salary()`
```python
Purpose: Input and process employee salary
Input: Interactive - Employee ID and basic salary
Output: Salary details and success/error message
Process:
  1. Get employee ID
  2. Verify employee exists
  3. Get basic salary amount
  4. Validate: positive number

     - HRA = basicSalary * 0.10
     - DA = basicSalary * 0.05
     - PF = basicSalary * 0.12
     - GrossSalary = basicSalary + HRA + DA - PF

  7. Display all components

Displayed Output:
  Basic Salary: Rs. [value]
  HRA: Rs. [value]
  DA: Rs. [value]
  PF: Rs. [value]
  Gross Salary: Rs. [value]
  Net Salary: Rs. [value]

Error Cases:
  - Empty employee ID
  - Employee not found
  - Non-numeric salary input
  - Negative salary
  - File save error
```

```python
Purpose: Calculate House Rent Allowance
```

#### `calculate_da(basic_salary)`

```python
Purpose: Calculate Dearness Allowance
Input: basic_salary (float) - Employee's basic salary

Formula: DA = basic_salary * 0.05
Example: calculate_da(50000) returns 2500.0
```

#### `calculate_pf(basic_salary)`
```python
Purpose: Calculate Provident Fund
Input: basic_salary (float) - Employee's basic salary
Output: float - Calculated PF amount
Formula: PF = basic_salary * 0.12
Example: calculate_pf(50000) returns 6000.0
```

```python
        print("Error: Salary cannot be negative!")
```

## 6. Calculation Methods

### 6.1 Salary Calculation Formula

```
HRA = BasicSalary * 0.10 (10%)
DA = BasicSalary * 0.05 (5%)
PF = BasicSalary * 0.12 (12%)

GrossSalary = BasicSalary + HRA + DA - PF
NetSalary = GrossSalary
```

### 6.2 Example Calculation

**Input:** Basic Salary = Rs. 25,000

**Step 1: Calculate Components**
- HRA = 25,000 × 0.10 = 2,500
- DA = 25,000 × 0.05 = 1,250
- PF = 25,000 × 0.12 = 3,000

**Step 2: Calculate Gross**
- Gross = 25,000 + 2,500 + 1,250 - 3,000 = 25,750

**Step 3: Calculate Net**
- Net = 25,750 (no additional deductions)

### 6.3 Aggregate Calculations

```
Total Basic = SUM(all BasicSalary values)
Total HRA = SUM(all HRA values)
Total DA = SUM(all DA values)
Total PF = SUM(all PF values)
Total Gross = SUM(all GrossSalary values)
Total Net = SUM(all NetSalary values)
```

### 7.1 Time Complexity

| Operation | Complexity | Notes |
|-----------|-----------|-------|
| Add Employee | O(n) | Reads all employees to find max ID |
| View Employee | O(n) | Linear search through employees |

- Scales with number of employees

### 7.3 Optimization Opportunities

- Indexing by ID for O(1) lookups
- Database instead of CSV for scalability
- Lazy loading for large datasets

## 11. Troubleshooting Guide

### Issue: "FileNotFoundError"

**Cause:** Program doesn't have write permission
**Solution:** Move to Documents or Desktop folder

### Issue: "Invalid literal for int()"

**Cause:** User entered non-numeric value
**Solution:** Program catches this, shows error message

### Issue: CSV file corrupted

**Cause:** Manual editing or interrupted save
**Solution:** Delete file, program recreates on next run

### Issue: Employee not found

**Cause:** Wrong ID entered
**Solution:** Use 4.1 to view all employees and get correct ID

### Issue: Salary showing as 0

**Cause:** Salary not entered yet
**Solution:** Use 2.1 to enter salary before generating slip
