INSTALLATION STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install Python
─────────────────────────────────────────────────────────────────────────────

1. Download Python from: https://www.python.org/downloads/
2. Choose Python 3.8 or higher (latest recommended)
3. During installation:
   ✓ Check "Add Python to PATH"
   ✓ Check "Install pip"
   ✓ Click "Install Now"

4. Verify installation:
   Open Command Prompt and type:
   
   C:\> python --version
   Python 3.10.0  (or similar version number)
   
   If version displays, Python is installed correctly!

STEP 2: Install MySQL Server
─────────────────────────────────────────────────────────────────────────────

1. Download MySQL from: https://dev.mysql.com/downloads/mysql/
2. Choose "MySQL Community Server" (latest version)
3. Run the installer
4. During setup:
   ✓ Choose "Developer Default" or "Server only"
   ✓ Accept default port 3306
   ✓ Set root password to: 1234
   ✓ Configure MySQL as Windows Service

5. Verify installation:
   Open Command Prompt and type:
   
   C:\> mysql --version
   mysql Ver 8.0.xx MySQL Community Server (should appear)

6. Test MySQL connection:
   
   C:\> mysql -h localhost -u root -p1234
   
   mysql>
   
   If you see "mysql>" prompt, connection successful!
   Type: exit

STEP 3: Create Database
─────────────────────────────────────────────────────────────────────────────

1. Open Command Prompt
2. Connect to MySQL:
   
   C:\> mysql -h localhost -u root -p1234

3. Create database:
   
   mysql> CREATE DATABASE IF NOT EXISTS mydb;
   Query OK, 1 row affected (0.01 sec)
   
   mysql> SHOW DATABASES;
   (You should see "mydb" in the list)
   
   mysql> exit

STEP 4: Install Python MySQL Connector
─────────────────────────────────────────────────────────────────────────────

1. Open Command Prompt
2. Install package:
   
   C:\> pip install mysql-connector-python
   
   Successfully installed mysql-connector-python-8.0.33

3. Verify installation:
   
   C:\> python -c "import mysql.connector; print('MySQL Connector installed!')"
   MySQL Connector installed!

STEP 5: Set Up Program Files
─────────────────────────────────────────────────────────────────────────────

1. Create a folder for the project:
   Example: C:\Users\YourName\Desktop\SFMS
   
2. Copy the file school_fee_management.py to this folder

3. Verify file exists:
   C:\SFMS> dir
   school_fee_management.py

PROBLEM 1: "Database connection failed"
┌─────────────────────────────────────────────────────────────────────────┐
│ Possible Causes:                                                        │
│ • MySQL server is not running                                          │
│ • Database 'mydb' doesn't exist                                        │
│ • Credentials are incorrect                                            │
│                                                                         │
│ Solution:                                                              │
│ 1. Start MySQL Server                                                 │
│    Windows: Services → MySQL80 → Start                                │
│    Or: net start MySQL80 (in Command Prompt as Admin)                 │
│                                                                         │
│ 2. Verify database exists:                                            │
│    C:\> mysql -h localhost -u root -p1234                             │
│    mysql> SHOW DATABASES;                                             │
│    (You should see 'mydb')                                            │
│                                                                         │
│ 3. Check credentials in program:                                      │
│    Should be: localhost / root / 1234                                 │
│    (Open school_fee_management.py and check line ~40)                │
└─────────────────────────────────────────────────────────────────────────┘

PROBLEM 2: "mysql-connector-python not found"
┌─────────────────────────────────────────────────────────────────────────┐
│ Cause: Python MySQL package not installed                              │
│                                                                         │
│ Solution:                                                              │
│ C:\> pip install mysql-connector-python                               │
│ C:\> pip list (verify installation)                                   │
│                                                                         │
│ If still not working:                                                 │
│ C:\> python -m pip install --upgrade pip                              │
│ C:\> python -m pip install mysql-connector-python                     │
└─────────────────────────────────────────────────────────────────────────┘

PROBLEM 3: "Invalid input" or validation errors
┌─────────────────────────────────────────────────────────────────────────┐
│ Cause: Incorrect data entry                                            │
│                                                                         │
│ Examples:                                                              │
│ • Email without @ symbol → "❌ Invalid email format!"                 │
│ • Phone with letters → "❌ Phone number must contain only digits!"   │
│ • Negative fee amount → "❌ Fee amount must be greater than 0!"      │
│ • Student ID that's not a number → "❌ Student ID must be a number!"│
│                                                                         │
│ Solution:                                                              │
│ Follow the error message and enter correct data format                │
└─────────────────────────────────────────────────────────────────────────┘

PROBLEM 4: "No student found with ID"
┌─────────────────────────────────────────────────────────────────────────┐
│ Cause: Wrong student ID entered                                        │

IMPORTANT INFORMATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. DATABASE CREDENTIALS
   Host:     localhost
   User:     root
   Password: 1234
   Database: mydb

   (These are configured in line 40-44 of school_fee_management.py)

2. DATABASE TABLES
   
   Student Table:
   ├── student_id (Primary Key, Auto-increment)
   ├── name (Student name)
   ├── roll_number (Unique)
   ├── class (Class and section)
   ├── email (Email address)
   ├── phone (Phone number)
   ├── address (Address)
   └── date_of_admission (Admission date)
   
   Fee Table:
   ├── fee_id (Primary Key, Auto-increment)
   ├── student_id (Foreign Key)
   ├── total_fee (Total amount)
   ├── paid_amount (Amount paid)
   ├── pending_amount (Remaining amount)
   ├── status (PAID/PENDING/PARTIAL)
   └── assigned_date (Assignment date)
   
   Payment Record Table:
   ├── payment_id (Primary Key, Auto-increment)
   ├── student_id (Foreign Key)
   ├── fee_id (Foreign Key)
   ├── payment_amount (Payment amount)
   ├── payment_date (Payment timestamp)
   ├── payment_method (Cash/Cheque/Online)
   └── remarks (Additional notes)

3. STATUS VALUES
   PAID     = Full fee paid
   PARTIAL  = Partial payment received
   PENDING  = No payment received yet

4. AUTO-CALCULATIONS
   pending_amount = total_fee - paid_amount
   status automatically updates based on payment
   student deletion cascades to all related records
