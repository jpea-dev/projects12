## Key Features Demonstrated in Output

1. **Menu-Driven Interface:** Clear hierarchical menu structure
2. **Data Persistence:** Data retained across sessions
3. **Input Validation:** Error messages for invalid inputs
4. **Automatic ID Generation:** Sequential passenger and ticket IDs
5. **Formatted Tables:** Well-organized data display
6. **Real-Time Updates:** Seat counts updated after each transaction
7. **Status Tracking:** Bookings marked as Confirmed or Cancelled
8. **Summary Statistics:** Total bookings and status counts shown
9. **Confirmation Messages:** Clear success/error feedback
10. **Professional Formatting:** Consistent borders and spacing
