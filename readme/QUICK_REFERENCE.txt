                      🗄️ DATABASE SCHEMA
════════════════════════════════════════════════════════════════════════════════

STUDENT TABLE
├─ student_id (Primary Key, Auto-increment)
├─ name (Student name)
├─ roll_number (Unique identifier)
├─ class (Class and section)
├─ email (Email address)
├─ phone (Phone number)
├─ address (Address)
└─ date_of_admission (Admission date)

FEE TABLE
├─ fee_id (Primary Key, Auto-increment)
├─ student_id (Foreign Key)
├─ total_fee (Total amount)
├─ paid_amount (Paid amount)
├─ pending_amount (Remaining amount)
├─ status (PAID/PENDING/PARTIAL)
└─ assigned_date (Assignment date)

PAYMENT_RECORD TABLE
├─ payment_id (Primary Key, Auto-increment)
├─ student_id (Foreign Key)
├─ fee_id (Foreign Key)
├─ payment_amount (Payment amount)
├─ payment_date (Payment timestamp)
├─ payment_method (Payment method)
└─ remarks (Additional notes)
