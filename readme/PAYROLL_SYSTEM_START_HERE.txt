## Example Workflow

1. **Add Employee**
   - Choose 1.1
   - Enter: Name, Designation, Department
   - Get auto-generated ID (1001, 1002, etc.)

2. **Enter Salary**
   - Choose 2.1
   - Enter Employee ID and Basic Salary
   - System calculates HRA, DA, PF automatically

3. **Generate Slip**
   - Choose 3.1
   - Enter Employee ID
   - Professional salary slip displayed

4. **View Reports**
   - Choose 4.1 - All employees
   - Choose 4.2 - Salary details
   - Choose 4.3 - Total expenditure

## Salary Calculation Example

**Input:** Basic Salary = Rs. 20,000

**Automatic Calculations:**
- HRA (10%) = 2,000
- DA (5%) = 1,000
- PF (12%) = 2,400

**Result:**
- Gross Salary = 20,600
- Net Salary = 20,600
