## Salary Calculation Reference

### Formulas Used

```
HRA (House Rent Allowance)  = BasicSalary × 0.10
DA (Dearness Allowance)     = BasicSalary × 0.05
PF (Provident Fund)         = BasicSalary × 0.12

GrossSalary = BasicSalary + HRA + DA - PF
NetSalary   = GrossSalary
```

### Example Calculations

**Example 1: Basic = Rs. 20,000**
- HRA = 2,000 | DA = 1,000 | PF = 2,400
- Gross = 20,600 | Net = 20,600

**Example 2: Basic = Rs. 50,000**
- HRA = 5,000 | DA = 2,500 | PF = 6,000
- Gross = 51,500 | Net = 51,500

**Example 3: Basic = Rs. 35,000**
- HRA = 3,500 | DA = 1,750 | PF = 4,200
- Gross = 36,050 | Net = 36,050
