# EMPLOYEE PAYROLL SYSTEM - QUICK START GUIDE

## What is This Program?

The Employee Payroll System is a Python-based application that helps manage employee records and calculate their salaries automatically. It stores all data in simple CSV files that can be easily accessed.

---

## Installation & Setup

### Step 1: Check Python Installation
Open Command Prompt and type:
```
python --version
```
You should see Python 3.x installed. If not, download from python.org

### Step 2: Save the Program
Save `employee_payroll_system.py` in a folder (e.g., Desktop or Documents)

### Step 3: Run the Program
1. Open Command Prompt
2. Go to your program folder: `cd Desktop`
3. Type: `python employee_payroll_system.py`
4. Program starts with Main Menu

---

## Main Menu Options

```
1. EMPLOYEE MANAGEMENT    - Add, View, Update, Delete employees
2. PAYROLL MANAGEMENT    - Enter and calculate salaries
3. SALARY SLIP           - Generate formatted salary slips
4. REPORTS               - View summaries and expenditure
5. Exit                  - Close the program
```

---

## Common Tasks

### Add an Employee
1. Choose: `1.1`
2. Enter: Name, Designation, Department
3. Get: Auto-generated Employee ID
4. Data saved automatically

### Calculate Salary
1. Choose: `2.1`
2. Enter: Employee ID
3. Enter: Basic Salary (e.g., 25000)
4. System automatically calculates:
   - HRA (10% bonus)
   - DA (5% bonus)
   - PF (12% deduction)
   - Gross & Net Salary

### View Salary Slip
1. Choose: `3.1`
2. Enter: Employee ID
3. Professional salary slip displayed
4. Shows all earnings and deductions

### Get Reports
1. Choose: `4.1` - All employees list
2. Choose: `4.2` - Salary details for each employee
3. Choose: `4.3` - Total company payroll

---

## Salary Calculation Example

**Input:** Basic Salary = Rs. 20,000

**Calculations:**
- HRA (10%) = 20,000 × 0.10 = Rs. 2,000
- DA (5%) = 20,000 × 0.05 = Rs. 1,000
- PF (12%) = 20,000 × 0.12 = Rs. 2,400

**Final Salary:**
- Gross Salary = 20,000 + 2,000 + 1,000 - 2,400 = Rs. 20,600
- Net Salary = Rs. 20,600

## Troubleshooting

### Problem: "Python not found"
**Solution:** Install Python from python.org and add to PATH

### Problem: "employees.csv not found"
**Solution:** Run program once; it will create the file automatically

### Problem: "Permission denied"
**Solution:** Save program in Documents or Desktop folder

### Problem: "Invalid choice"
**Solution:** Use exact menu options like 1.1, 1.2, 2.1, etc.

### Problem: Data not saving
**Solution:** Check folder permissions; move to Desktop

---

## Data Entry Guidelines

### When Adding Employee:
- Name: At least 2 characters
- Designation: e.g., Manager, Developer, Clerk
- Department: e.g., IT, HR, Sales, Finance

### When Entering Salary:
- Basic Salary: Enter positive number only
- Example: 25000 or 50000.50
- Negative values will show error

### When Deleting Employee:
- Must confirm deletion with "yes"
- Cannot undo deletion - be careful!
