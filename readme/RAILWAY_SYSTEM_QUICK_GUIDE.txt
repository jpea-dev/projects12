# RAILWAY TICKET RESERVATION SYSTEM - QUICK REFERENCE GUIDE

## Quick Start

### Installation
1. Save `railway_reservation.py` to your computer
2. Open command prompt or terminal
3. Navigate to the file location
4. Type: `python railway_reservation.py`
5. Press Enter

## Passenger Management Module

### Add Passenger
- **Input Required:** Name, Age, Gender, Phone, Email
- **Auto-Generated:** Passenger ID (P001, P002, etc.)
- **Validation Rules:**
  - Name: Minimum 2 characters
  - Age: 1 to 120 years
  - Gender: M / F / Other
  - Phone: At least 10 digits
  - Email: Must contain @ and .
- **Storage:** passengers.csv

### View Passenger
- **Input Required:** Passenger ID
- **Output:** All passenger details
- **Error Handling:** Shows message if ID not found

## Ticket Reservation Module

### Booking Process
1. Enter Passenger ID (must be registered)
2. View available trains
3. Enter Train Number
4. System validates:
   - Passenger exists
   - Train exists
   - Seats available
5. Automatic actions:
   - Generate Ticket Number (TKT5001, TKT5002, etc.)
   - Reduce seat count by 1
   - Record booking with date
   - Display confirmation

### Output on Success
```
Ticket Number: TKT5001
Passenger ID: P001
Train Number: TR001
Train Name: Rajdhani Express
From Delhi to Mumbai
Ticket Fare: Rs. 1500
Booking Date: DD-MM-YYYY
```

### Error Cases
- Passenger not found
- Train not found
- No seats available

---

## Cancellation Module

### Cancellation Process
1. Enter Ticket Number (must be valid and confirmed)
2. System validates:
   - Ticket exists
   - Booking status is "Confirmed"
3. Automatic actions:
   - Change status to "Cancelled"
   - Increase seat count by 1
   - Display cancellation confirmation

### Output on Success
```
Ticket Number: TKT5001
Train Number: TR001
Status: Cancelled
```

### Error Cases
- Ticket not found
- Ticket already cancelled
- Invalid ticket number format

## Data Storage Details

### File 1: passengers.csv
```
Structure:
PassengerId | Name | Age | Gender | Phone | Email
Example:
P001 | Raj Kumar | 25 | M | 9876543210 | raj@email.com
```

### File 2: trains.csv
```
Structure:
TrainNumber | TrainName | Source | Destination | AvailableSeats | Fare
Example:
TR001 | Rajdhani Express | Delhi | Mumbai | 100 | 1500
```

### File 3: bookings.csv
```
Structure:
TicketNumber | PassengerId | TrainNumber | BookingDate | BookingStatus
Example:
TKT5001 | P001 | TR001 | 21-01-2026 | Confirmed
```

### File 4: ticket_counter.txt
```
Current ticket counter value (integer)
Example: 5001
```

## Important Validation Rules

### Passenger Registration
```
Name:    Minimum 2 characters required
Age:     Must be between 1-120 years
Gender:  Only M, F, or Other accepted
Phone:   Minimum 10 digits required
Email:   Must contain @ and . symbols
```

### Ticket Booking
```
Passenger: Must exist in passenger database
Train:     Must exist in train database
Seats:     Must be available (> 0)
```

### Ticket Cancellation
```
Ticket:    Must exist in booking database
Status:    Must be "Confirmed" (not already cancelled)
```

## Sample ID Formats

**Passenger ID:** P001, P002, P003, ...
- Format: P + 3-digit number
- Auto-generated sequentially

**Ticket Number:** TKT5001, TKT5002, TKT5003, ...
- Format: TKT + sequential number
- Starts from 5001
- Stored in ticket_counter.txt

**Train Number:** TR001, TR002, TR003, TR004, TR005
- Pre-defined in system
- Cannot be modified

## Troubleshooting

### Program won't start
- Check Python is installed: `python --version`
- Ensure file is in correct directory
- Run from command prompt, not file manager

### "File not found" error
- Program automatically creates files on first run
- Wait for "Success" messages before checking files

### Invalid input errors
- Read error message carefully
- Follow format rules (age must be number, phone must be 10 digits)
- Re-enter data in correct format

### Passenger registration fails
- Check name has at least 2 characters
- Check age is between 1-120
- Check email has @ and .
- Check phone has at least 10 digits

### Ticket booking fails
- Ensure passenger ID exists (register first)
- Ensure train number is correct (TR001-TR005)
- Check train has available seats

### Data seems lost
- Check files exist in program directory
- Don't delete CSV files while program runs
- Verify files have correct names
