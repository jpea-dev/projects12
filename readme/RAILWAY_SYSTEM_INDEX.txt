## SYSTEM MODULES

### Module 1: Passenger Management
**Functions:** add_passenger(), view_passenger(), passenger_menu()
**Features:** Register passenger, view details
**Storage:** passengers.csv

### Module 2: Train Management
**Functions:** view_trains(), get_train_details(), train_menu()
**Features:** View all trains, get specific train info
**Storage:** trains.csv

### Module 3: Ticket Reservation
**Functions:** book_ticket()
**Features:** Book ticket, auto-generate ticket number, reduce seats
**Storage:** bookings.csv, ticket_counter.txt

### Module 4: Ticket Cancellation
**Functions:** cancel_ticket()
**Features:** Cancel booking, restore seats
**Storage:** bookings.csv

### Module 5: Reports
**Functions:** view_all_bookings(), view_available_seats(), reports_menu()
**Features:** Show bookings, display seat availability
**Storage:** Read from CSV files

### Module 6: Train Utilities
**Functions:** get_train_details(), update_train_seats()
**Features:** Train data access, seat management
**Storage:** trains.csv

### Module 7: ID Generation
**Functions:** get_next_ticket_number(), get_next_passenger_id()
**Features:** Auto-generate unique IDs
**Storage:** ticket_counter.txt

### Module 8: Menu Interface
**Functions:** display_menu(), main()
**Features:** User interface, main loop
**Storage:** None (displays only)

## DATA FILES (Auto-created)

### passengers.csv
- Stores: Passenger information
- Fields: PassengerId, Name, Age, Gender, Phone, Email
- Created: First time passenger registered
- Format: CSV (comma-separated values)

### trains.csv
- Stores: Train information
- Fields: TrainNumber, TrainName, Source, Destination, AvailableSeats, Fare
- Created: On first program run
- Default: 5 sample trains

### bookings.csv
- Stores: Ticket booking records
- Fields: TicketNumber, PassengerId, TrainNumber, BookingDate, BookingStatus
- Created: First time ticket booked
- Status: Confirmed or Cancelled

### ticket_counter.txt
- Stores: Current ticket number counter
- Content: Single integer (starts at 5000)
- Updated: After each ticket generation
- Purpose: Sequential ticket number generation
